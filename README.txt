GRTEC WebAR - descarga al reconocer la fotografía

1. Mantén tu archivo REAL `fotografia.mind` dentro de assets/.
2. Este proyecto usa `assets/fotografia.jpg` como archivo que se descarga.
3. Sube `index.html` y `assets/fotografia.jpg` a la raíz de tu repo.
4. Conserva tu `assets/fotografia.mind`.
5. GitHub Pages debe publicar `main / (root)`.

Importante:
Los navegadores móviles pueden bloquear una descarga automática iniciada por un evento de cámara.
Por eso, al reconocer la fotografía se muestra también el botón "Descargar fotografía".
